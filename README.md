
# Automated Excel Report Generator Using Python

## Project Description
The Automated Excel Report Generator is a Python-based project that automates sales report creation. It collects product details, calculates total sales, organizes data, and generates a formatted Excel report with bar chart visualization. This project reduces manual effort, saves time, and improves accuracy in sales reporting.

## Objectives
- Automate sales report generation.
- Calculate total sales based on quantity and unit price.
- Generate formatted Excel reports.
- Visualize product-wise sales using bar charts.
- Reduce manual calculations and errors.

## Technologies Used
- Python
- Pandas
- Matplotlib
- OpenPyXL
- Colorama

## Features
- Accepts product name, quantity, and unit price.
- Automatically calculates total sales.
- Generates a formatted Excel report.
- Creates a bar chart to visualize sales data.
- Displays sales information clearly.

## Project Workflow
1. Enter product details.
2. Process and organize the data.
3. Calculate total sales.
4. Generate the Excel report.
5. Create and display the sales bar chart.

## Formula
**Total Sales = Quantity × Unit Price**

## Output Files
- `Automated_Report.xlsx` - Generated Excel sales report.
- `sales_chart.png` - Sales bar chart.

## Installation

Install the required libraries:

```bash
pip install pandas matplotlib openpyxl colorama
```

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code or PyCharm.
3. Install the required libraries.
4. Run the Python program:

```bash
python create_sales.py
```

5. Enter the requested product details.
6. View the generated Excel report and sales chart.
